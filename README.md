Customer Shopping Behaviour Analysis:
Overview:
Analysis of customer shopping data (~3,900 transactions) to understand customer behaviour, spending patterns, and subscription trends using Python, SQL, and Power BI.

Tools Used:
Python (Pandas, NumPy),MySQL,Power BI

Dataset:
Includes customer demographics, purchase details, ratings, discounts, shipping type, and subscription status.
Missing values handled and new features created during preprocessing.

Workflow:
Data cleaning & feature engineering in Python,Business queries using SQL
,Dashboard creation in Power BI

Key Insights:
Subscribers spend more than non-subscribers
,Discounts affect some products strongly
,Repeat buyers are more likely to subscribe
,Revenue differs by category, age group, and gender
